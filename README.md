## The word

> **scrollhole**

The whole internet, in one word: a hole you fall into by scrolling.
You open it for one thing, look up hours later, and you are somewhere
else entirely — one more video, one more thread, one more tab.

It is funny on its own, it says something true about the internet as a
whole (every site, every app, every feed is a scroll that swallows your
time), and it is not the first word anyone reaches for.

## How to run

Requires Node 22 or later. No dependencies.

```sh
node main.ts
```

This writes the entry word to `/output/entry.txt` (UTF-8, no trailing
newline).
